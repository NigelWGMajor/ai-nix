# MEM semantic note recall

Use /mem to search markdown notes in the current workspace root, rank the most relevant passages for a user question, and return quick-scan results with date, excerpt, and file:line links.

Best when:
- You remember a topic but not the file.
- You need fast evidence snippets from notes.
- You want a short relevance-ranked reading list.

Not for:
- Editing notes.
- Exhaustive full-text dumps.
- Non-markdown content unless user asks.
